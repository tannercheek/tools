Adding a tool

Save the HTML file into /tools/ and push. The card builds itself from four tags in the file's head: 
<title>Packing checklist</title>
<meta name="description" content="Trip kit, sorted by climate">
<meta name="icon" content="checklist">
<meta name="tags" content="checklist, travel">
To archive, move the file to /archive/. Nothing else to edit.
